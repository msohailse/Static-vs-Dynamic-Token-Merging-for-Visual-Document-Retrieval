Thesis experiment built on **ColPali v1.2** and the paper *"Towards Storage-Efficient Visual Document
Retrieval: An Empirical Study on Reducing Patch-Level Embeddings"* (Ma et al., ACL Findings 2025 —
`2025.findings-acl.1003.pdf` in this folder).

## The idea in one paragraph

ColPali turns every document page into ~1,030 patch embeddings, which makes the index huge. The paper's
Light-ColPali merges similar patches with one **fixed** merging factor (9 ⇒ ~11% of the memory) and notes
that dense text pages lose the most accuracy — choosing the factor **per page** is left as future work.
This project does exactly that: each page's **own patch embeddings** reveal how compressible it is
(`S = 1 − mean nearest-neighbour cosine similarity`; validated AUC 0.70 for separating text-rich from
low-density pages, where pixel heuristics fail). Attempt 1 picks one factor per page from S (dense pages
merged gently, redundant pages harder). Attempt 2 removes the per-page verdict entirely: the page's cluster
tree is cut by merge *distance* so each region chooses its own granularity, bounded by safety floors (never
harder than the paper's F=9 on a page that is dense or unsure, never harder than F=13 anywhere). Result on
57 real PDF documents (138 pages, incl. 20–25-page documents) with real queries: **the payoff is memory —
the index shrinks to a fraction of full ColPali and below even the paper's best static setting, while
accuracy stays at the baseline's level (no dataset falls below it).** Exact numbers are generated by the
run into `results/RESULTS.md`.

![Benchmark A: accuracy and memory per dataset](results/benchmark_a.png)

*Blue dotted = the paper's Static 9 (always F=9); orange = Attempt 2, violet = Attempt 1 (ours). Left:

*The mechanism: static pays the same ~114 vectors for every page; ours pays less exactly on the pages its
analysis is confident are redundant, bounded by the safety floors. Full method write-up: [`METHOD.md`](METHOD.md).*

## How to read the results

- Always read **accuracy and memory together** — Dynamic and Static 9 use different budgets.
- The fair test of the thesis is **Attempt 1 / Attempt 2 vs. Static 9** at the accuracy *and* memory they each reach.
- The paper's 97.8% retention at factor 9 comes from a model *fine-tuned with merging*; everything here is
  training-free, so compare the methods with each other, not with the paper's absolute numbers.
